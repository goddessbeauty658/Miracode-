# MIRACODE — Digital Studio

Responsive single-page portfolio built to match the approved MIRACODE showcase: deep navy and electric-blue palette, peach accents, bold typography, service cards, project gallery, about section, value propositions, contact enquiry and responsive navigation.

## Structure
- `index.html` — complete site markup, styles and interactions
- No framework or build step required; suitable for Cloudflare Pages static hosting.

## Before launch
1. Replace portrait placeholders with approved MIRACODE brand photography.
2. Set `WHATSAPP_NUMBER` in the script near the bottom of `index.html` to the full country-code number using digits only.
3. Add the confirmed business email and social profile links.
4. Review image licensing and availability.

## Cloudflare Pages
Connect this repository, select `main`, use `/` as the root directory, leave the build command blank, and leave the build output directory blank for this plain HTML site.
